# חיפוש מתקדם בדף הבית: תחום "תפוסה" (4.10.2026)

**למה.** הבעלים ביקש בדיקת תפוסה בסינון המתקדם ("בסינון מתקדם - לא ביקשתי בדיקת תפוסה?"). התחום קיים בעיצוב המאושר
(`תצוגות-עיצוב/סיימתי-לעבוד/דף-הבית.html`: `capacity:{ label:'תפוסה', icon:'box', blocks:[{ t:'cap' }] }`, "פרטי תפוסה", "סיכום תפוסה")
ובשרת (`app/api/a5/adv-b/route.js`, הפונקציה `capacity`), אבל דף הבית האמיתי דילג עליו ב-V1 כ"איטי".

## מה נוסף
| חלק | איפה | מה |
|---|---|---|
| תחום | `app/components/home/homeAdvConfig.js` → `ADV_FOCI.capacity` | בשורת התחומים הראשית אחרי משלוחים (כמו בעיצוב), אייקון `box`. `keys` = רק `model/size/from/to` נשלחים לשרת; `required` = דגם |
| הרשאה | `FOCUS_PAGE.capacity = '/orders'` | `page:orders` — אותו שער כמו `GATE.capacity` בשרת, ההצעות (`/api/a5/options`) ו-`/stock-check`. בלי הרשאת הזמנות התחום לא מוצג בכלל; בלי `boot` — שום תחום (נעילה סגורה) |
| טופס | `HomeAdvanced.js`, בלוק `cap` | "פרטי תפוסה": דגם ומידה עם הצעות מהשרת (אותו `OptionField` כמו בשאר התחומים), "תאריך אירוע" + "עד תאריך" בבורר העברי, מסומנים כטווח |
| בדיקה לפני שליחה | `advMissing` + `HomeA5.applyAdv` | בלי דגם: טוסט "חסר שדה חובה" עם הנוסח של השרת ("נדרש דגם לחיפוש תפוסה") — בלי קריאה לשרת |
| טעינה | `HomeAdvanced` (`loading`) | בזמן החישוב כפתורי החיפוש נעולים והכפתור הראשי מציג את הספינר של שורת החיפוש (`mspin`). מונע שליחה כפולה של החישוב הכבד |
| תוצאות | `HomeAdvResults.js` | אריחי `.capstats` (במלאי / בתפוסה / רזרבה, מהפלטה) מתחת לשורת הסיכום — גם כשאין הזמנות; שורות/טבלה, "עוד N", ייצוא — כמו בשאר התחומים |
| שגיאות | `HomeA5.js` | 400 (חסר דגם / יותר מ-`CAPACITY_PAIRS_MAX` צמדי דגם+מידה) = טוסט עם הודעת השרת והטופס נשאר פתוח; 403 = "אין הרשאה"; 500 = כרטיס שגיאה, ו"לנסות שוב" מריץ שוב את החיפוש המתקדם (קודם הריץ את החיפוש הכללי האחרון) |

תיקונים קטנים שנמצאו בדרך (משפיעים על כל התחומים): עמודה שלישית בלי כותרת בטבלת החיפוש המתקדם כשאין סטטוס; מעבר/חזרה בין תחומים בזמן טעינה מבטל את החיפוש שבטעינה.

## בדיקות
`node scripts/test_home_logic.mjs` (קטע "חיפוש מתקדם: תפוסה" — מקום ותוויות, שער זהה לשרת, בקשה, שדה חובה, הודעות השרת, סיכום עברי, `capstats`),
`node scripts/home-bg-audit/run.mjs [1280|375] [light|dark]` — שלבים 27-35 (טופס, תוצאות, טבלה, טעינה, דגם חובה, מגבלת צמדים, שגיאה, "לנסות שוב") עם API מדומה.

## הבדלים מהעיצוב (מכוונים / משותפים לכל התחומים)
- תצוגת **לוח שנה** (כפתור שלישי במתג) לא קיימת בדף האמיתי לאף תחום — גם לא לתפוסה.
- בטבלה: עמודות "שם / פרטים" כמו בשאר התחומים בדף האמיתי; בעיצוב עמודות השרת ("שם, תאריך אירוע, כמות, טלפון").
- כותרת הטוסט במגבלת הצמדים היא "חסר שדה חובה" (כמו באב-טיפוס `public/a5`), הטקסט הוא הודעת השרת.

## עלות בשרת (לשים לב)
כל צמד דגם+מידה = 3 שאילתות ב-`/api/inventory/capacity`, ובשאילתת התפוסה אין גבול תחתון לתאריך ב-SQL (נטענים כל פריטי ההזמנות של הדגם+מידה, הסינון ב-JS).
בלי מידה = כל מידות הדגם (עד 30 צמדים, 5 במקביל). ל-`adv-b` אין `maxDuration` (ב-`/api/stock-check` יש 30).
