# תור המתנה לאישור מרוכז — פריטים שלא ביקש הגמח השני

קובץ זה נוצר לבקשת משה (2026-09-23) כדי לחסוך במספר המיזוגים הנפרדים (וכפועל יוצא,
במספר הדיפלויים ל-Vercel שנספרים במגבלה היומית של החשבון).

**מה נכנס לכאן**: כשהסוכן האוטומטי (`fix-reports.md`) מתקן דיווח עבור גמח אחד, ותוך
כדי כך מזהה ששינוי הקוד המשותף גם רלוונטי/מועיל לגמח השני — למרות שהוא לא דיווח
ולא ביקש את זה — הענף/PR עדיין נפתח כרגיל, אבל השורה מתועדת **כאן בלבד**, לא
בתגובת-הסיכום לדיווח, לא ב"יומן הסוכן" ולא בסיכום הצ'אט של אותה הרצה. ר' הסעיף
"גמח שלא דיווח בעצמו על אותה תקלה — לתור המתנה, לא להודעה מיידית" ב-
[.claude/commands/fix-reports.md](../.claude/commands/fix-reports.md).

**מתי הקובץ הזה נקרא**: רק כשמשה מבקש במפורש ("מה ממתין באישור מרוכז", "תראה לי את
התור" וכדומה), או בסבב-מיזוגים מרוכז (על ידי משה או הרצת Claude Code אחרת שהוא
מפעיל) — שם עוברים על כל השורות למטה, בודקים שה-PR הרלוונטי עדיין פתוח ולא מוזג,
ומאשרים/ממזגים את כולם יחד.

**פורמט שורה**: `- YYYY-MM-DD | PR #<num> (<קישור>) | גמח <1/2> | <משפט קצר למה זה רלוונטי לגמח הזה>`

**אחרי מיזוג**: מחקו את השורה מהקובץ הזה (היא כבר לא ממתינה).
