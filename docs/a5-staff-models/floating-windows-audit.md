### נייד 390
חלונות הכרטיס (הוספה, עריכה, לא פעיל, מחיקה), אישורי הרשימה, חלון הסטטיסטיקה: גיליון תחתון באורך מלא, בלי גלילה אופקית (`scrollWidth == viewport`). בחלון הסטטיסטיקה סרגל הכלים עובר לשורה משלו מעל העיגול בנייד (בפינה הוא נגע בעיגול).

## מה שונה בקבצים
- `app/components/StatisticsModal.js` (+ חדש `app/components/statistics-modal.css`): הוסב לחלון כהה. נשען על אותם `DialogFrame` / `ConfirmDialog` / `MessageDialog` ו-`ai-dialogs.css` של עוזר ה-AI (הפלטה כבר נטענת בכל האתר דרך `AIFloatingWidget`, כך שאין עלות CSS נוספת בדפים הישנים). נמחקו `lucide-react`, `.modal*`, `window.customConfirm`, `alert()`.
- `app/components/dress-card/css/dress-card.css`: 8 שורות - טוקני `--k-*` ל-`.dc-barc`, `.dc-err`, `.hv-r`, `.empty` בתוך `#dlg/#dlg2`.
- `scripts/test_a5_floating_windows.mjs` (חדש, 8 בדיקות): אין חלונות דפדפן במסכים החדשים; StatisticsModal כהה + אותו API + שכבה 2 + Escape; CSS מוגבל ומבוסס טוקנים.

## נקודות תיעוד / פתוח
1. **מאחר ש-StatisticsModal משותף**: כל הדפים הישנים שמארחים אותו (orders / customers / rentals / alterations / board / employees הישן) מקבלים עכשיו חלון כהה. אם הבעלים רוצה שהדפים הישנים יישארו בהירים - צריך דגל; כרגע ההוראה היא "כל החלונות כהים".
2. מקרה ה-`position` (מיקום ליד הלחיצה) בוטל: החלון תמיד ממורכז (גיליון תחתון בנייד). ה-prop נשאר בחתימה.
3. כפתור `#debug-toggle-btn` (`ClipboardDebugger`, z-index 999998, למתכנת בלבד) יושב מעל גיליונות תחתונים בנייד ומסתיר את לחצן השליחה בחלון הסטטיסטיקה - רק בסביבת פיתוח / למתכנת, לא חלק מהעיצוב.
4. מדידת הניגודיות אוטומטית מתעלמת מרקעי גרדיאנט (לחצני זהב) - אלה נבדקו בעין (טקסט שחור על זהב).
5. לא נבדק בפועל: חלון "יוצר את הדגם" (דורש יצירת דגם), כשל שמירה חלקי של הכרטיס (דורש כשל שרת), ואירוע ריחוף אמיתי לטולטיפ (הפאנל הוא תצוגה מוסתרת). שלושתם נבדקו בקוד.
6. הערת בדיקה: ה-pane מרענן את הדף בכל עריכת קובץ של סוכן אחר (HMR) ומאבד חלון פתוח - מריצים את הסקריפט מחדש אחרי טעינה מלאה.
