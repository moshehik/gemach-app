# מדריך האתר של עוזר ה-AI ("ai-site-guide") - 12.10.2026

בקשת הבעלים (נושא 10): עוזר ה-AI (הכוכב) ענה על "איך עושים X" עם הוראות של האתר הישן ("תפריט צד"). נדרשת הפרדה יסודית: **מהיום העוזר
עונה רק בהקשר של הממשק החדש (תפריט עליון, A5)**, יכול **להצביע** על כל מקום באתר (קישור לדף + הדגשת האלמנט), ותשובותיו נבדקות מול המציאות.

## מה היה (למה העוזר ענה לפי הישן)
- `lib/howToGuide.js` - קטלוג ידני של 23 "פעולות נפוצות" שנכתב לפני התפריט העליון: "תפריט הצד", "קישור מהיר בעמוד הבית" וכו'.
  `app/api/ai/route.js` (חוק 21 + `ACTION: HOWTO_GUIDE()`) ו-`app/api/ai/statistics/route.js` ענו אך ורק ממנו. אין בו הרשאות, אין ארגונים, אין נגזרות מהקוד.
- `lib/settingsMetadata.js` (`buildSettingsGuide`) נגזר מהקוד אך נתן מיקום `הגדרות מערכת ← <קטגוריה>` בלי קשר למסך ההגדרות החדש.
- שאלות שלא נתפסו ע"י ACTION נענו מידע כללי של המודל (הוזיות).

## הארכיטקטורה החדשה
```
lib/aiGuide/
  schema.js          חוזה: יעד (target), מזהה, תגית [[guide:ID]], קישור עומק ?gm_guide=
  areas/<אזור>.targets.js   יעדי הצבעה (נתונים בלבד - נטען גם בדפדפן)
  areas/<אזור>.js           דפים (pages), משימות (tasks), skip (שרת בלבד)
  targetsIndex.js    רישום היעדים לדפדפן ;  index.js  הרישום המלא לשרת ולבדיקות
  access.js          הרשאות/זמינות יעד, דף ומשימה למשתמשת מסוימת (כשל-סגור)
  knowledge.js       בונה את "הידע": תפריט מעץ buildMenuTree האמיתי של המשתמשת, אינדקס דפים, משימות, יעדים רלוונטיים
  resolve.js         אימות תגיות ההצבעה של המודל (מזהה מהרישום בלבד; נפילה לאב; בלי URL/סלקטור חופשי)
  serverContext.js   טוען הרשאות/הגדרות/עץ תפריט/תצוגה (ישן-חדש) למשתמשת
lib/ai/siteGuide.js  הזרימה: ACTION: SITE_GUIDE() -> ידע -> מודל -> אימות -> הערת ממשק -> ניסיון חוזר אם הוזכר "תפריט צד"
app/components/guide/GuideProvider.js (+guide.css)  ההדגשה בדפדפן
scripts/test_ai_site_guide.mjs     בדיקת הרישום והזרימה (נכשלת כשחסר יעד/דף)
scripts/ai-site-guide/{eval,grade}.mjs + questions.json   בדיקת מציאות מול /api/ai האמיתי (TEST בלבד)
```
**הפרדה מהישן**: הרישום מתאר רק את הממשק החדש. מה שהוסר מהתפריט הישן נגזר מ-`REMOVED_ITEMS` ב-`lib/menu/buildMenuTree.js` ומוצג למודל כ"הוסר - אל תנחה אליו".
תצוגה ישנה של המשתמשת (`lib/uiVariant.js`) מזוהה בשרת: אם היא עדיין בתפריט/מסך הישן, נוספת לתשובה שורה קבועה (בקוד, לא מהמודל) שמסבירה שההוראות
לתפריט החדש ואיפה האייקון שמעביר אליו. תשובה שהזכירה בכל זאת "תפריט צד" נכתבת מחדש פעם אחת (ו-`meta.legacyMention` מדווח).

## מה המודל מקבל
תפריט עליון כפי שהמשתמשת רואה אותו (נגזר מ-`buildMenuTree` עם ההרשאות וההגדרות שלה: למשל "משלוחים" רק כשמופעלים, "ניהול" מצומצם לעובדת רגילה),
אינדקס כל הדפים שמותר לה לפתוח (שם | נתיב | איך מגיעים), פירוט הדפים הרלוונטיים לשאלה (`about`, `can`, `cannot`), משימות מאומתות צעד-צעד, ורשימת היעדים
להצבעה (id | שם | איפה). דירוג הרלוונטיות לקסיקלי (בלי מודל נוסף) ב-`knowledge.js`.

## "הצבעה" על אלמנטים
- כל יעד: מזהה יציב `אזור.שם` (למשל `menu.order-new`), שם בעברית, `aliases`, `route`, `data-guide-id` על האלמנט בקוד, `reveal` (איך חושפים: פתיחת תפריט
  הסרגל / לחיצה על לשונית או כפתור), `where`, `hint`, `parent` (נפילה), `access`.
- המודל מסיים את התשובה ב-`[[guide:ID]]` (עד 4, לפי סדר הצעדים). השרת מאמת מול הרישום וההרשאות, מסיר את התגיות ומחזיר `guide: [{id,label,where,route}]`;
  הווידג'ט מציג כפתור **"הצג לי"** (ו"צעד 1/3"). אין URL או סלקטור שמגיע מהמודל: ב-`GuideProvider` הניווט נלקח מהרישום בלבד.
- קישור עומק שאפשר לשתף: `/orders/new?gm_guide=no.step-customer` (הפרמטר נקרא וניקה מהכתובת). API בדפדפן: `window.gmGuide.show([...ids])`.
- התנהגות: ניווט לדף, חשיפת התפריט/לשונית, גלילה למרכז, הילה + בועת הסבר, המתנה לאלמנט שנטען באיחור (עד 5 שניות), נפילה ליעד האב עם הודעה ידידותית,
  Esc / לחיצה מחוץ / "הבנתי" / סגירה אוטומטית אחרי 16 שניות, RTL ונייד (תפריט המבורגר), `prefers-reduced-motion`, צבעי הפלטה (`--gm-*`) בלבד.

## איך מוסיפים יעד / דף / משימה חדשים
1. **אלמנט חדש להצבעה**: הוסיפו `data-guide-id="<אזור>.<שם>"` לאלמנט (בלי לשנות עיצוב), ורשומה ב-`lib/aiGuide/areas/<אזור>.targets.js`
   (`id, label, aliases, route, where, kind, reveal?, parent?, access?`). אלמנט שנבנה בתבנית (`oc.tab-${id}`) - הצהירו `dynamic` באותו קובץ.
2. **פריט תפריט חדש** ב-`lib/menu/buildMenuTree.js` / **כלי ניהול חדש** ב-`lib/adminHubCatalog.js`: הבדיקה נכשלת עד שמוסיפים יעד (`menuItem` / `hubTool`).
3. **דף חדש** (`app/**/page.js`): רשומה ב-`pages` של האזור (`title` כמו ב-`lib/menu/pageLabels.js`, `ui`, `access`, `about`, `can`, `reach`) או ב-`skip` עם סיבה.
4. **משימה "איך עושים"**: ב-`tasks` של האזור; בצעדים השתמשו ב-`{{label:ID}}` / `{{path:ID}}` כדי שהשמות יישארו מסונכרנים עם הקוד.
5. הריצו: `npm run test:ai-guide` (או `node --no-warnings --import ./scripts/ai-reliability/register.mjs scripts/test_ai_site_guide.mjs [--area <אזור>]`).
