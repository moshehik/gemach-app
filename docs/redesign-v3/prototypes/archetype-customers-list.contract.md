## UI בלבד מול דורש נתונים (רק מה שהוכח)
**UI בלבד (אותן קריאות, אותם שדות):**
- סטטוס "חסום" בשורה (תג יחיד — סטטוס אמיתי, `isBlocked` כבר בתשובה) + סיבה בשורה המורחבת (`blockedReason`).
- טבלה מצומצמת: קוד · שם מלא · טלפון · עיר (מוסתרת מתחת ל-1024) · מצב; טלפון נוסף, מייל, כתובת (`street`,`houseNum`,`city`), ת"ז (`zeout`, מוצג חלקית) ואישור דיוור (כשלא מוסתר) בשורה המורחבת — כולם בתשובה.
- מיון לפי שם משפחה/שם פרטי נשאר (בורר מיון) גם כשהעמודה היא "שם מלא".
- מצב ריק (3 סוגים: אין לקוחות / אין תוצאות לחיפוש / אין תוצאות לסינון), מצב שגיאה + "לנסות שוב" (אותה קריאה), שלד טעינה.
- `.hf-pill` לכל שדה סינון מתקדם פעיל (הסרה בלחיצה) + מונה על כפתור "סינון" + החלה רק ב"הצגת התוצאות" + חזרה לעמוד 1 (שינוי התנהגות — CQ-2).
- הסתרת כפתורי AI/סטטיסטיקה כש-`hide-ai-features` (אותו class שכבר קיים).
- באנר מצב חכם + "חזרה לרשימה"; השבתת מיון בכותרות במצב חכם (במקום חץ מטעה).
- ייצוא `legacyId` בעמודת "קוד לקוח" (השדה כבר בתשובה).
- כרטיסי רשימה בטלפון; שורה נגישה (קישור לשם).

**דורש נתונים/API (לא קיים היום):**
- יתרת חוב/זכות ללקוח ברשימה — ה-API לא מחזיר (`route.js:66-90`; אבחון 03 §6.2).
- מספר הזמנות / הזמנה אחרונה ללקוח — לא מוחזר.
