## רגרסיה (הורץ על הקובץ הסופי)
- `check.cjs`: media רק מהסט; מאפיין פיזי יחיד = `left` של toast (חריג מתועד §ד.6); אין `alert/confirm`; אין `pageerror` ב-4 הרוחבות; `scrollWidth ≤ clientWidth` ב-360/768/1024/1440; 0 כפתורים בלי תווית.
- `flows.cjs` מלא: חצים RTL (prev=`i-back` חץ ימינה מימין, next=`i-next` חץ שמאלה משמאל); תפריט בתוך המסך גם בעמודה השמאלית; Esc סוגר תפריט ומחזיר פוקוס; כרטיס ריחוף בתוך המסך; חלונית פרטים `dark` + נעילה + `inert` + scrim מעל הסרגל העליון + גלגלת לא מגלגלת; חלון יום `light` (scrim סוגר — נבדק גם בלחיצה; כרטיס השכרה — scrim לא סוגר); 3 שכבות `light/light/dark`; Esc ×3 אחת-אחת; NoticeBar ב-72px מתחת לסרגל (64), טיימר `paused` בריחוף; toast 26px משמאל / 24px מלמטה; קוד `light` אחרי החלפת ערכה; Enter על כרטיס → תפריט עם פוקוס על פריט; טלפון: רשימה כברירת מחדל, מקרא מקופל, תפריט = גיליון תחתון, רשת חודש = מספר + מונה (30 ימים ניתנים להקשה), חלון יום; פרופיל קיצוני + יום עם 14 הזמנות בשלוש התצוגות ב-360/768/1024 בלי גלישה.
- **לא הורץ:** axe, קורא מסך, מכשיר מגע/iOS אמיתי, גופן Rubik (חסום ברשת), `verify-board.cjs` של הבונה (כותב לתיקייה שלו).
