# חוזה עמוד — כרטיס לקוחה (`archetype-detail-card`, ארכיטיפ A2)

מקור: קריאת קוד אמיתי של `/customers/[id]` (`app/customers/[id]/page.js` +
`components/customers/modern/{ModernCustomerCard,ModernCustomerDetailsTab,
ModernCustomerOrdersTab,ModernCustomerPaymentsTab,ModernCustomerRefundsTab,
ModernCustomerHistoryTab}.js`) — **פונקציונליות בלבד, לא markup/CSS**. כל
פריט = `P-nn`. מבנה החזות (לא הפונקציונליות) נקבע ע"י `order-card-sketch-B.html`
+ טבלת ארכיטיפ A2 ב-`CONSTITUTION.md §ו`, לא ע"י העמוד הישן.

זהו החוזה עבור **`docs/redesign-v3/prototypes/archetype-detail-card.html`** —
פרוטוטייפ סטטי (HTML אחד, נתוני דמה) שהבעלים מאשר לפני שנוגעים בעמוד האמיתי
(Phase 3). **לא** קריאות API אמיתיות, **לא** state אמיתי — רק החזות/מבנה.

## מצבי קצה חובה (C-9.3) — לכל רכיב בפרוטוטייפ
1. שם לקוחה קצר (2 תווים) / ארוך מאוד (60+ תווים, שני שמות משפחה) — `line-clamp` בכותרת, לא שובר פריסה.
2. 0 הזמנות / 1 הזמנה / 50+ הזמנות (גלילה בלשונית, לא בעמוד).
3. חוב גדול (7 ספרות) / זכות / מאוזן בדיוק 0.
4. כל שדה אופציונלי חסר בו-זמנית (לקוחה "ריקה" — רק שם+טלפון).
5. הערות ארוכות מאוד (פסקאות רבות, כולל כמה הערות אוטומטיות ברצף).
6. חסומה + חוב + הרבה הזמנות בו-זמנית (כל התגיות/באנרים ביחד).
7. רוחב: 360 / 768 / 1024 / 1440 / 1920 — הרייל הופך ל-bottom sheet מתחת ל-1024 (D-6/§ג.1).

## מה שלא נכלל בכוונה (ולמה)
- **חסימת לקוחה (לא רק ביטול)**: אין כפתור "חסימה" בעמוד האמיתי היום (`isBlocked:true` נכתב רק אוטומטית, `app/api/customers/route.js:85`) — לא בודים פעולה שלא קיימת.
- **מנוע שינויים אמיתי (undo/redo לכל שדה)**: P-10 היא רשימה **לקריאה בלבד** לפי CONSTITUTION §ז.4 ("עד ההחלטה — העמוד מציג רשימת שינויים לקריאה בלבד") — אין כפתורי undo פר-שורה בפרוטוטייפ, רק "בטל הכול" (P-11), זהה ליכולת הקיימת היום.
- **התאמת מלל org**: כל הטקסט בפרוטוטייפ הוא ברירת המחדל מ-`strings/he.js`-style — לא בונים override מוצג, כי אין הבדל מלל מתועד לכרטיס לקוחה בין הארגונים.
