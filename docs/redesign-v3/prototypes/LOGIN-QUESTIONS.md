# שאלות פתוחות — מסך הכניסה (archetype-login)

סוכן אוטונומי, בלי אפשרות לשאול. לכל שאלה: מה נבחר כברירת מחדל באב-הטיפוס. **הכול לאישור הבעלים.**

| # | שאלה | ברירת המחדל שנבחרה | למה |
|---|---|---|---|
| Q-L1 | **מנהלי סיסמאות**: להפעיל שמירה/מילוי של סיסמאות (שדה `username` נפרד + `current-password`, LG-32) או להשאיר חסום כמו היום? | **כבוי כברירת מחדל** (= היום). העיצוב בנוי כך שאפשר להדליק: מתג "תמיכה במנהלי סיסמאות" בבקרת ההדגמה | מחשב משותף בגמח: שמירת סיסמאות של כמה עובדים באותו דפדפן היא החלטת אבטחה, לא עיצוב. חייב בדיקה בדפדפן אמיתי (LG-33) לפני מימוש |
| Q-L2 | **שני צעדים** (שם ← קוד) במקום טופס אחד? | כן — כל צעד עם פעולה ראשית אחת; אותו state ואותן קריאות | מפריד את הרשימה משדה הסיסמה (שורש באג ה-dropdown הכפול), מאפשר כותרת אישית "שלום, {שם}", ומתאים לגובה מסך נמוך |
| Q-L3 | מאיפה שם הגמח והלוגו במסך הכניסה (לפני כניסה אין סשן)? | props מ-`app/layout.js` (כבר קורא `SystemSetting` בצד שרת) + `/api/logo` הקיים. **לא** לפתוח את `/api/settings` לאנונימי | לא לחשוף הגדרות לאורחים |
| Q-L4 | התראת "הודעות שלא טופלו" אחרי כניסה (LG-35) — היום נבלעת ע"י `reload()` | באב-הטיפוס לא מוצגת על מסך הכניסה; מוצע להעביר ל-NoticeBar אחרי הטעינה (שינוי לוגי — מחוץ לתחום) | כך היא תופיע באמת |
| Q-L5 | כישלון טעינת רשימת העובדים — היום רק console | מצב "הרשימה לא נטענה" + "לנסות שוב" (קריאה חוזרת לאותו endpoint) | אחרת העובד רואה "אין שם כזה" ולא מבין מה קרה. תוספת לוגיקה קטנה — לאישור |
| Q-L6 | נעילה אחרי ניסיונות כושלים | **לא קיימת בשרת** ⇒ לא מוצגת. אזור השגיאה יכול להכיל הודעה כזו אם תתווסף | R8: לא ממציאים פונקציונליות |
| Q-L7 | Esc בחלונית הכניסה (מתוך תפריט המשתמש) — ב-v3 סוגר, בישן לא | באב-הטיפוס: Esc **סוגר** רק כשהשדות ריקים; אם הוקלד משהו — לא סוגר (מונע אובדן הקלדה). ה-X תמיד סוגר | פשרה בין עקביות שכבות לבין הסיכון שתועד ב-verify-login |
| Q-L8 | הצגת/הסתרת סיסמה (עין) במסך הראשי — קיימת רק בקיוסק | כן, בשני המצבים (סיסמה ו-PIN) | עוזר לטעויות הקלדה; הצגה בלבד |
| Q-L9 | "זכור אותי" / זיכרון העובד האחרון במחשב | **לא** — לא קיים ולא הומצא | R8 |
| Q-L10 | הודעות השרת בכתיב ישן ("סיסמא שגויה", "אנא פנה למנהל") | מוצגות כלשונן | שינוי מלל שרת = שינוי API, מחוץ לתחום. מומלץ לעדכן בנפרד |
| Q-L11 | האם להשאיר את ה-aside השיווקי ("כל הגמח, במקום אחד" + 3 יתרונות) | **הוסר** | עובד שנכנס כמה פעמים ביום לא צריך שיווק; זה מה שהפך את הכניסה ל"עוד כרטיס" |
| Q-L12 | שם הארגון ארוך מאוד (70+ תווים) | עד 3 שורות באזור הזהות, 2 ברצועה בטלפון, `…` + tooltip עם השם המלא | C-9.3 |
| Q-L13 | כלל ריסון הצ'יפים C-1.14 לא נמצא ב-CONSTITUTION שבענף הבסיס (`redesign/v3-protos-review`) ולא נמצא ענף `redesign/v3-protos-polish` ב-remote בזמן הריצה | יושם לפי המשימה: **אין צ'יפים בכלל** במסך | הוראת המשימה |
| Q-L14 | סימון עובד שנבחר ברשימה: ראשי-תיבות בעיגול | כן (אין תמונות ב-API האנונימי) | LG-9 |
| Q-L15 | "מחשב מהימן" — איך להציג בלי צ'יפ | שורת מידע שקטה (אייקון מגן + טקסט + ⓘ) מעל שדה הקוד, רק במחשב מהימן | C-1.14 |
