## 1. מלאי הסקיצה — כל מה שהיא מציגה

### 1.6 לשונית משלוח (S:2222-2246)

### 1.7 לשונית תשלומים (S:2247-2290)
- אריח **זיכוי פעיל** עם ספירה לאחור 15 דק׳ + "ביטול זיכוי" (`creditile`).
- **מצב תשלום**: יתרה (חוב/זכות/שולם), פס התקדמות שולם/מתוך, כפתור "תשלום ₪X" / "זכה ₪X".
- **חיובים** (רשימה + שורות "ממתין לשמירה" מהשינויים הלא-שמורים) — tooltip "מתעדכן אוטומטית".
- **תשלומים שהתקבלו** (אמצעי, תאריך, הערה, סכום; זיכוי שלילי).
- אקורדיון **אפשרויות מנהל**: רישום תשלום ידני, בקשת זיכוי, חישוב מחדש + הסבר "רגילים לא צריכים".

### 1.8 לשונית היסטוריה (S:2296-2376)
כותרת + מונה; **חיפוש** בתוך הפיד (הדגשת `<mark>`, ניקוי); **סינון רב-בחירה** (הכל/פריטים/תשלומים/משלוח/תאריכים/מסמכים + חתימות/הדפסות/מיילים/תיקונים דינמי, עם מוני ספירה, כרטיסיות-פיל, ניווט מקלדת); פיד **מקובץ לפי יום** בתאריך עברי מלא + לועזי; שורה מתקפלת: אווטאר מבצע, שעה, פרטים, "שינוי: לפני ← אחרי", שדות נוספים; תג סכום (תשלום/חיוב/זיכוי); מצב ריק "לא נמצאו רישומים" + איפוס; שורה חדשה עם `enter`.

### 1.9 מסילת סיכום (`rail`, S:2378-2440)
- **Glance**: חתימה (חתום/לא חתום, לחיץ), משלוח (כיוון), מספר פריטים, מצב תשלום — כל אחד עם tooltip עשיר.
- **עגלת שינויים** ("שינויים בהזמנה"): מונה, סכום נטו, שורה לכל שינוי (הוספה/הסרה/תיקון/משלוח/כתובת/יום לפני/תאריך/הערה/חתימה) עם **ביטול פר-שינוי** ו-**redo**; סה״כ "חיוב/זיכוי ממתין", "לתשלום אחרי שמירה".
- כפתורים דינמיים: "שמור ושלם ₪X" / "שמור וקבל זיכוי ₪X" / "שמור" / "שלם ₪X בלבד" / "בטל שינויים" / "זכה ₪X" / "שלם ₪X"; צ'יפ זיכוי עם ספירה לאחור (`crchip`).

### 1.10 חלוניות (S:2470-2560, 2828-2930)
1. **סיכום שינויים** (שמירה / יציאה עם שינויים): רשימת שינויים + סכומים, נטו; כפתורים שמור(ושלם/וקבל זיכוי) · צא בלי לשמור / בטל שינויים · חזרה לעריכה.
2. **תשלום**: סכום, אמצעי (מזומן/אשראי/העברה/צ׳ק), אישור תשלום, "השאר חוב (באישור מנהל)".
3. **זיכוי**: בחירה "זיכוי לניצול על פריט חלופי (15 דק׳)" / "החזר כספי"; אישור.
4. **פרטי בנק**: שם בעל חשבון + IBAN (אימות ≥8 תווים).
5. **הצלחה**: "ההזמנה נשמרה" + הזמנה חדשה / הדפסה / לרשימה / המשך לצפות.
6. **לבטל את כל השינויים?** (S:2736).
7. **מחיקת הזמנה** (S:2712) — "אפשר לשחזר מפריטים מחוקים".
8. **מייל מהיר** (בהיר בלבד): נמען, כותרת, תוכן (מונה תווים), 6 קבצים מצורפים (סיכום, תקנון חתום*, תשלומים, משלוח*, חשבונית, תמונות ZIP) עם תצוגה מקדימה/הסרה/גודל, 6 תבניות טקסט (אישור, תזכורת לקיחה/החזרה, עדכון משלוח, תשלום פתוח, חופשי), מצבי שליחה idle/sending/done, חסימת קבצים שלא קיימים.
9. **זרוק את המייל?** (מגן נטישה).
10. **אישור מנהל**: 4 ספרות, שגיאה + shake, נעילה אחרי 3 ניסיונות, שורת "שרה לוי · מנהלת".
