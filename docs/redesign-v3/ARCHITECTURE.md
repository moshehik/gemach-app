# ארכיטקטורה ושיטת עבודה

## 1. הספריות המשותפות (R2)
```
app/v3/
  tokens.css        ← מקור אמת יחיד: צבעים, גדלים, מרווחים, רדיוסים, צללים, תנועה, גופן.
  components.css    ← מחלקות רכיבים (prefix v3-): כרטיס, כפתור, צ'יפ, שדה, טאב, טבלה, טיימליין, חלונית, טוסט, tooltip...
  icons.js/.svg     ← ספריית האיקונים + האנימציות שלהם (איקון = שם, לא SVG מקומי בעמוד)
  ui/               ← רכיבי React דקים שעוטפים את המחלקות: <V3Page> <Card> <Btn> <Chip> <Field> <Tip> <Icon>
                       <Stepper/Timeline> <Dialog> <Toast> ...
  copy/             ← מלל אחיד (מילון מחרוזות) — "כתיבה מחדש" במקום אחד
```
- **prefix `v3-`** לכל המחלקות — לא מתנגש עם `.btn` / `.card` הישנים, ולכן העמודים עוברים אחד-אחד והאתר נשאר עובד לאורך כל הדרך.
- **סקופ:** עמוד שהומר עטוף ב-`<V3Page>` (מוסיף `data-v3` על השורש). ה-tokens מוגדרים תחת `[data-v3]`.
- **בסוף** (שלב מיזוג/ניקוי, באישור המשתמש): מעבר גלובלי + מחיקת CSS ישן (`design-overrides.css`, חלקים מ-`globals.css`/`design-system.css`).
- **פלטות משתמש:** מערכת הפלטות הקיימת (`Employee.themeColor`, `customPalette`) — ראו IDEAS-LOG #1. ברירת מחדל: פלטת סקיצה B (navy/sky/gold + pink רק על כפתורים/תגים).

## 2. שיטת הסוכנים (רעיון 12 — נבחר, בשינוי קל)
**קבוצה א' — בעלי סגנון (Builders).** סוכן לכל *משפחת עמודים* (למשל: "רשימות+טבלאות", "כרטיס-פרט", "אשף שלבים", "לוח/דשבורד", "טפסים", "הדפסות", "קיוסק לקוחות", "חלוניות"). כל אחד בונה את העמודים שלו מול הספריות בלבד, ומחזיק את ה"סגנון" של המשפחה עקבי.
**קבוצה ב' — סוקרים (Reviewers).** סוכנים לפי *ממד*, לא לפי עמוד: RTL · מלל+tooltips · איקונים+אנימציה · חלוניות (כהה/בהיר) · התאמת-לוגיקה 100% · היסטוריה · נגישות/ביצועים. כל סוקר עובר על **כל** העמודים והחלוניות וכותב בקשות לקובץ `requests/<family>.md` של הבעלים הרלוונטי.
**מחזור:** בנייה (א') → סקירה (ב') → תיקון בקשות (א') → אימות 100% (ב'-אימות). אין תקשורת ישירה בין סוכנים — רק קבצי הבקשות (מקור אמת אחד, ניתן לביקורת).
**למה זה חכם יותר:** הסוקרים רואים דפוסים חוצי-עמודים (אותו באג RTL ב-20 מקומות → תיקון בספרייה, לא ב-20 עמודים); הבעלים שומרים עקביות פנימית.
**כלל ברזל:** באג שחוזר ביותר מ-2 עמודים ← מתקנים ב-`app/v3/` ולא בעמוד (העדפת המשתמש: תיקון שיטתי ברמת ה-CSS).
