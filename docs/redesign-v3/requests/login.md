# בקשות - משפחת login

## REQ-1 · LoginScreen · ספרייה (מחלקות) · קוסמטי
מה: אין מחלקות למעטפת כניסה (פס מותג, גריד כרטיס+אייד, ריבוע-מנעול, רשימת יתרונות) - כרגע inline עם tokens. במובייל (<640) אמור להסתתר רשימת היתרונות ולהישאר רק הכותרת; זה לא ניתן ב-inline.
איפה: app/components/LoginScreen.js (בלוק `loginCard` במצב עמוד מלא)
איך לתקן (הצעה): `.v3-auth`, `.v3-auth__bar`, `.v3-auth__grid`, `.v3-auth__mark`, `.v3-auth__perks` ב-components.css.
סטטוס: פתוח

## REQ-2 · LoginScreen · Combobox · בינוני
מה: קומבובוקס העובדים בנוי ידנית מ-`v3-combo__*` עם רשימה בזרימה (לא absolute) כי הוא יושב בתוך Dialog גולל. חסר רכיב `<Combobox>` בספרייה עם טיפוס inline-list + ניווט מקלדת.
סטטוס: פתוח

## REQ-3 · LoginScreen · Dialog · קוסמטי
מה: ל-`Dialog` אין `initialFocus` שמונע פוקוס אוטומטי בשדה (במצב חלונית-כניסה הפוקוס הראשון הוא כפתור הסגירה/שדה העובד שפותח את הרשימה).
סטטוס: פתוח
