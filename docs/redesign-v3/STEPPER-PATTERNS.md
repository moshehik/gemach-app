# דפוסי תהליכי שלבים ב-v3 (R22)

מקורות: ציר הזמן של סקיצה B (`sketch/order-card-sketch-B.html`: `.stepper` שורות 85-96, `.tx` / `.tlx` שורות 840-844 ו-2086, `.tl` להיסטוריה שורות 252-257, אנימציות `fade`/`pop`/`popin` שורות 116, 305, 892) + אשף ההעלאה של מדפיס-בוט (`print-center/app/upload/UploadWizard.js` + `upload-wizard.css`). קוסמטי בלבד (R8): לא משנים סדר שלבים, ולידציות, מצב, ולא שום קריאת API.

## 1. מה לוקחים מכל מקור

### מסקיצה B (השלד החזותי)
- **מסלול צמתים**: עיגול 40px, קו חיבור עבה 4px בין צמתים; צבעי מצב: `done` = navy מלא + סימן וי, `cur` = זהב עם טבעת זוהרת (`box-shadow 0 0 0 6px`), עתידי = לבן עם מסגרת sky. תווית מודגשת מתחת + שורת משנה (`span`, ink3).
- **קו חלקי** (`.linkcur`): הקו שיוצא מהשלב הנוכחי מתמלא 40% - מסמן "בדרך".
- **הכל בתוך כרטיס ממוסגר** (R13), גופן 16px+ (R14), RTL עם `inset-inline-*` (R17).
- **מסלול מחליף היסטוריה**: `.tl` האנכי משמש להיסטוריה/ציר-זמן של אירועים, לא לשלבי מילוי.

## 2. הדפוס המאוחד ("סטפר v3")

```
[פס מקטעים דק - מובייל בלבד]
┌─ כרטיס ממוסגר ─────────────────────────────────────────────┐
│  (1)━━━━(2)━━━━(3)╌╌╌╌(4)╌╌╌╌(5)    ← צמתי B: done=navy+✓,  │
│  לקוח  תאריכים פריטים סיכום תשלום      cur=זהב+טבעת          │
│  ישראל  12.10   3 פריטים               ← שורת ערך (summary)  │
└───────────────────────────────────────────────────────────┘
        שלב 3 מתוך 5                    ← עוגן, muted
        אילו פריטים בהזמנה?              ← כותרת גדולה
  ┌ תוכן השלב (fade-up 0.38s) ─────────────────────────────┐
  │ שדות: תווית מעל, ערך מתחת (R15) · ⓘ צף להסברים (R11)   │
  │ אזור הודעת ולידציה (aria-live) כשצריך                   │
  └────────────────────────────────────────────────────────┘
  [→ חזרה ללקוח]                          [ להמשך: סיכום ← ]
```

כללים:
1. **צומת לחיץ** רק אם `enabled` (כמו `canNavigateToStep`); צומת חסום מציג `lockedReason` ב-tooltip צף (R11) - **לא** `alert()` כמו היום (`orders/new/page.js:1444-1448`).
2. **שלב שהושלם** = וי מונפש (`popin`, שורה 892), הקו שאחריו מתמלא בירוק/נייבי בתנועה (`transition .5s`).
3. **שלב נוכחי** = זהב + `nowpulse` עדין (שורה 867), נעצר ב-reduced-motion.
4. **גוף השלב** עם `key={step}` וכניסת `fade`; ללא אנימציית יציאה (מהיר).
5. **פוטר ניווט** קבוע: חזרה (ghost, סוף-שורה) · המשך (ראשי, תחילת-שורה). בשלב האחרון: כפתור הפעולה הסופית עם תווית פועל ("שמירת הזמנה"). מובייל: פוטר דביק תחתון.
6. **מובייל (<640px)**: צמתים 34px, תוויות מקוצרות מתחת ל-`ellipsis`, שורת ערך מוסתרת (נשארת רק בצומת הנוכחי), גלילה עדינה לצומת הנוכחי, פס מקטעים מעל.
7. **שלב מותנה** (דוגמת "שילוב קבצים"): מספר הצמתים משתנה דינמית; העוגן "שלב X מתוך N" מתעדכן.
8. **עריכה מסיכום**: כל בלוק בסיכום כולל "עריכה" שמחזיר לשלב, ואחרי "המשך" חוזר ישר לסיכום.

## 3. הצגת ולידציה
- שדה חסר: מסגרת סגולה/זהב-אדום (`--red` = gold-700 של B) + הודעה קצרה מתחת לשדה, `aria-describedby`.
- שלב חסום: כפתור "המשך" נראה `disabled` **עם** ⓘ צף שמסביר מה חסר (במקום הדיסאבל השקט של היום, `orders/new/page.js:1579`).
- ניסיון קפיצה קדימה: כמו ב-PermissionRowWizard (`:88-96`) - חוזר לשלב הבעייתי הראשון ומציג את ההודעה שם; נשמר.
- שגיאת שרת: `callout` בראש הגוף, לא toast בלבד; toast רק לאישור הצלחה (R20).
- לא משנים אף כלל ולידציה - רק את ההצגה.

## 5. רכיבים משותפים מוצעים (ל-`app/v3/ui`)
- `V3Stepper` (props: `steps[{id,label,value,enabled,lockedReason}]`, `current`, `onStep`, `compact`) - מחליף את שלושת הסטפרים (#1,#2,#3).
- `V3StepFooter` (props: `backLabel`, `nextLabel`, `onBack`, `onNext`, `nextDisabled`, `nextHint`, `sticky`).
- `V3StepBody` - עוטף `key` + `fade` + עוגן "שלב X מתוך N" + כותרת.
- `V3StepMeter` - פס מקטעים (מובייל) / פס התקדמות רציף (#7).
- כולם ב-`components.css`, בלי ערך קשיח (R2); אנימציות מכבדות `prefers-reduced-motion` (R12).
